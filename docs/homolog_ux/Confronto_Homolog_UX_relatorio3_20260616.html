Onboarding — Cadastro, Login e Assistente da Empresa

Findings F01–F14 sobre trial expirado, LGPD, marca, contatos, endereço, revisão e aceite de termos.

F01 Trial expirado bloqueia acesso sem CTA de conversão ALTO ✓ Verificado - ok
Módulo: Login pós-trial
Antes (relatório consultora)
Após expiração do trial, o sistema exibe mensagem de assinatura inativa sem botão de renovação ou contratação.
Depois (ação corretiva / estado atual)
login.component.ts exibe CTA "Assinar agora" (/billing) e link comercial quando code=SUBSCRIPTION_INACTIVE.
Evidência
código verificado
F02 E-mail do usuário exposto em query string na URL pós-cadastro (risco LGPD) ALTO ✓ Verificado - ok
Módulo: Pós-cadastro trial
Antes (relatório consultora)
URL de redirecionamento continha email= em texto plano após criar conta trial.
Depois (ação corretiva / estado atual)
trial-signup grava e-mail em sessionStorage (aerosuite.trialSignupEmail); login consome e remove; URL só trialCreated=1.
Evidência
código verificado
F03 Tagline/slogan pré-preenchida com o nome da organização MEDIO ✓ Verificado - ok
Módulo: Assistente — Etapa Marca
Antes (relatório consultora)
Campo tagline era inferido automaticamente do nome comercial.
Depois (ação corretiva / estado atual)
TenantSignupService e wizard mantêm tagline vazia por padrão; placeholder orientativo sem inferência do nome.
Evidência
código verificado
F04 Logo e wordmark carregam assets de outro tenant — falha multi-tenant CRITICO ✓ Verificado - corrigido
Módulo: Assistente — Etapa Marca
Antes (relatório consultora)
URLs globais /api/public/empresa-asset/logo|wordmark serviam assets compartilhados entre organizações.
Depois (ação corretiva / estado atual)
Uploads por tenant (saveLogoForTenant/saveWordmarkForTenant); endpoints públicos por tenantCodigo; globais retornam 404; wizard inicia sem URL de asset alheio.
Evidência
código corrigido; deploy necessário para 404 do endpoint global em homolog
F05 Cor primária alterada para preto (#000000) sem ação do usuário ALTO ✓ Verificado - ok
Módulo: Assistente — Etapa Marca
Antes (relatório consultora)
Color picker nativo podia emitir #000000 por race condition na inicialização.
Depois (ação corretiva / estado atual)
brand-primary-color-input ignora #000000 espúrio do input nativo quando a cor atual não é preta.
Evidência
código verificado
F06 Elementos não interativos recebem borda de foco de formulário MEDIO ✓ Verificado - ok
Módulo: Assistente — Etapas 2 e 4
Antes (relatório consultora)
Blocos descritivos e área de botões exibiam outline verde indevido.
Depois (ação corretiva / estado atual)
SCSS do wizard remove outline/box-shadow de .form-hint, .wizard-header__sub, .wizard-review__intro e .wizard-actions.
Evidência
código verificado
F07 E-mail de contato pré-preenchido com domínio .local inválido ALTO ✓ Verificado - ok
Módulo: Assistente — Etapa Contatos
Antes (relatório consultora)
Sistema gerava contato@org.local automaticamente no signup.
Depois (ação corretiva / estado atual)

Evidência
código verificado
F08 Campo telefone aceita texto livre e não valida em tempo real ALTO ✓ Verificado - ok
Módulo: Assistente — Etapa Contatos
Antes (relatório consultora)

Depois (ação corretiva / estado atual)

Evidência
código verificado
F09 Campo telefone não limita quantidade de dígitos ALTO ✓ Verificado - ok
Módulo: Assistente — Etapa Contatos
Antes (relatório consultora)
Sequência de dígitos acima de 11 caracteres era aceita.
Depois (ação corretiva / estado atual)

código verificado
F10 Toast de erro sem auto-dismiss adequado MEDIO ✓ Verificado - ok

Depois (ação corretiva / estado atual)

F12 Botões da revisão desalinhados e com borda visual indevida MEDIO ✓ Verificado - ok
