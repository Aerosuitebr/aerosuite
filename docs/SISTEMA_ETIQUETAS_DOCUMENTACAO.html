📦 Visão Geral do Sistema

O Sistema de Etiquetas Integradas da Aero Suite Controls foi desenvolvido para garantir a rastreabilidade completa de todos os produtos e componentes aeronáuticos que passam pelo estoque da empresa. Através de códigos QR e códigos de barras tradicionais, cada item pode ser identificado, localizado e ter seu histórico consultado instantaneamente.

✅ Benefícios Principais

  • Rastreabilidade Total: Histórico completo desde a entrada até o consumo
  • Agilidade: Consulta instantânea com leitores de código de barras
  • Conformidade: Atende requisitos de qualidade aeronáutica
  • Flexibilidade: 5 tamanhos de etiqueta para diferentes necessidades
  • Integração: Conectado ao sistema de gestão Aero Suite

📏 Tamanhos de Etiquetas Disponíveis

O sistema oferece 5 tamanhos padronizados de etiquetas, cada um otimizado para diferentes tipos de produtos e necessidades operacionais. A escolha do tamanho correto é fundamental para garantir a legibilidade e praticidade no dia a dia.

Etiqueta Completa Recomendada

100mm × 80mm (4" × 3.15")

Todas as informações: QR Code, código de barras, fornecedor, lote, invoice e localização.

✓ QR Code ✓ Barcode ✓ Detalhes Completos

Etiqueta Padrão

100mm × 50mm (4" × 2")

QR Code + Código de Barras + P/N, S/N e localização. Ideal para uso geral.

✓ QR Code ✓ Barcode ✓ Info Básica

Etiqueta Média

80mm × 40mm (3.15" × 1.57")

QR Code + P/N e S/N. Sem código de barras tradicional.

✓ QR Code ✓ P/N + S/N

Etiqueta Compacta Compacta

60mm × 40mm (2.4" × 1.6")

QR Code + Part Number apenas. Para peças de tamanho médio.

✓ QR Code ✓ P/N

Etiqueta Mínima

40mm × 30mm (1.57" × 1.18")

Apenas QR Code com código. Para componentes muito pequenos.

✓ QR Code

💡 Dica de Escolha

Regra geral: Use o maior tamanho que couber no item ou na embalagem. Etiquetas maiores são mais fáceis de escanear e têm informações mais legíveis.

Passo a Passo Detalhado

1

Entrada de Mercadoria

Acesse o módulo Estoque → Entrada de Mercadoria. Preencha os dados da Invoice, fornecedor e itens recebidos.

2

Cadastro do Item

Para cada item, informe: Part Number, Serial Number (se houver), quantidade, localização no estoque, certificações e observações.

3

Geração Automática do Código

Ao salvar, o sistema gera automaticamente o código de rastreio no formato BLW-AAAA-MM-XXXXX (ex: BLW-2026-01-00042).

4

Seleção do Tamanho

Na tela de sucesso ou na lista de itens, clique em "Imprimir Etiqueta". O sistema exibirá um modal com os 5 tamanhos disponíveis.

5

Impressão

Selecione o tamanho adequado e clique em "Imprimir". A etiqueta será enviada para a impressora configurada.

6

Fixação no Item

Cole a etiqueta em local visível do item ou embalagem. Evite dobras sobre os códigos QR e de barras.

Acesso Rápido (Atalho F2)

⌨️ Atalho de Teclado

Em qualquer tela do módulo de Estoque, pressione F2 para abrir diretamente a tela de Consulta por QR Code. Isso agiliza o processo de verificação de itens com leitores de código de barras.

📱 QR Code e Código de Barras

O sistema utiliza duas tecnologias complementares de identificação automática: QR Code para smartphones e tablets, e Código de Barras Code128 para leitores tradicionais de código de barras.

📱 QR Code

  • Formato QR Code Version 2
  • Conteúdo Código de Rastreio
  • Correção de Erro Nível M (15%)
  • Biblioteca qrcode.js (CDN)

📊 Código de Barras

  • Formato Code128 (auto)
  • Conteúdo Part Number
  • Altura 35-50px (variável)
  • Biblioteca JsBarcode (CDN)

Flexibilidade de Busca

A tela de Consulta por QR Code aceita múltiplos formatos de busca, permitindo encontrar itens mesmo sem o código de rastreio completo:

Tipo de Busca Exemplo Resultado
Código de Rastreio BLW-2026-01-00042 Item específico
Part Number 123-456-789 Lista de itens com mesmo P/N
Serial Number ABC123456 Item específico
Busca Parcial 456 Itens que contenham "456"

⚠️ Importante

Leitores de código de barras tradicionais só conseguem ler o código de barras Code128 (Part Number). Para ler o QR Code, é necessário um leitor 2D ou smartphone/tablet.

✅ Boas Práticas

Posicionamento da Etiqueta

✓ Correto

  • Superfície limpa e seca
  • Local visível e acessível
  • Sem dobras sobre os códigos
  • Temperatura ambiente na aplicação

✗ Evitar

  • Superfícies oleosas ou sujas
  • Locais de atrito constante
  • Aplicação em baixa temperatura
  • Dobrar a etiqueta na embalagem

Armazenamento de Insumos

📦 Condições de Armazenamento

  • Etiquetas: Ambiente seco, temperatura 15-25°C, longe de luz solar direta
  • Ribbons: Embalagem original fechada até o uso, mesmas condições das etiquetas
  • Validade: Utilizar dentro de 12 meses da fabricação para melhor adesão

Procedimento de Verificação

Após imprimir a etiqueta, sempre verifique:

Item Verificação Ação se Falhar
QR Code Escanear com smartphone Reimprimir, verificar ribbon
Código de Barras Escanear com leitor Verificar configuração Code128
Texto legível Leitura visual Aumentar contraste/verificar ribbon
Adesão Tentar descolar levemente Limpar superfície, usar etiqueta adequada

🔧 Solução de Problemas

Problemas Comuns e Soluções

❓ QR Code não é lido pelo scanner

Causas possíveis:

  • Impressão com baixa resolução → Usar impressora 300 DPI
  • QR Code muito pequeno → Usar tamanho de etiqueta maior
  • Ribbon gasto → Trocar ribbon
  • Leitor 1D (só lê barcode) → Usar leitor 2D

❓ Etiqueta não adere corretamente

Causas possíveis:

  • Superfície oleosa → Limpar com álcool isopropílico
  • Temperatura muito baixa → Aplicar em ambiente aquecido
  • Etiqueta inadequada para material → Usar BOPP ou poliéster
  • Etiqueta vencida → Verificar data de fabricação

❓ Impressão borrada ou fraca

Causas possíveis:

  • Ribbon incompatível com etiqueta → Verificar combinação ribbon/etiqueta
  • Cabeça de impressão suja → Limpar com álcool e cotonete
  • Temperatura de impressão baixa → Aumentar nas configurações
  • Velocidade muito alta → Reduzir velocidade de impressão

❓ Tamanho da etiqueta não corresponde ao impresso

Causas possíveis:

  • Driver não configurado → Configurar tamanho nas preferências da impressora
  • Navegador alterando escala → Usar "Escala: 100%" na impressão
  • Margem do navegador → Remover cabeçalho/rodapé de impressão

Manutenção Preventiva

Frequência Ação Material
Diária Verificar estoque de etiquetas -
Semanal Limpar cabeça de impressão Álcool isopropílico + cotonete
Mensal Limpar sensores e rolos Pano seco + ar comprimido
Trimestral Verificar desgaste de componentes Manutenção técnica se necessário
