Destaques das correções

  • Integridade de dados (A10): validação de e-mail no cadastro trial — fim das organizações duplicadas.
  • Segurança (A22/A26/A71): erros de banco e HTTP sanitizados — nada de SQL ou URL expostos ao usuário.
  • Onboarding (A15/A18/A19/A31): máscaras BR, CEP automático e redirecionamento ao dashboard após configuração.
  • Sessão (A32): timeout por inatividade com aviso prévio de 2 minutos.
  • Fabricantes (A49/A57/A52): cancelar sem erro, inativação lógica e paginação padrão de 10 itens.
