S4-07 Falha ao salvar produto com nome de 255 caracteres (limite do frontend) CRITICO ✓ Verificado - ok
Módulo: Cadastro — Novo Produto
Antes (relatório consultora)
Frontend anunciava limite de 255 caracteres no contador, mas o backend falhava com erro genérico ao persistir.
Depois (ação corretiva)

Evidência de verificação

Como reproduzir
POST /products com name 255 chars — status 201 após deploy (verify-relatorio6 S4-07-api).
