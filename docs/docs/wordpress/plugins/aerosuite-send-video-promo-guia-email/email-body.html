Guia de Produção do Vídeo Promocional

Gravação · CapCut · Abacus

Olá, Thiago,

Segue em anexo o Guia de Produção do Vídeo Promocional Aero Suite, preparado para você produzir um vídeo de alta qualidade (60–90 s) a partir da gravação do tour do produto.

O PDF contém:

  • Checklist completo de pré-gravação (tenant demo, tema, idioma)
  • Roteiro passo a passo — teleprompter de ações (~8 min brutos)
  • Texto de narração pronto para TTS no Abacus
  • Prompts copy-paste para Abacus (cortes, upscale, B-roll, voz)
  • Legendas sugeridas, compliance de copy e checklist de publicação
  • Modelo para mapear timestamps quando o vídeo bruto estiver pronto
Fluxo recomendado: gravar aerosuite-demo-bruto.mp4 → cortar no CapCut (90 s + legendas) → Abacus só para upscale, B-roll hangar e narração. Não aplicar efeitos cinematográficos sobre a UI.

Quando tiver a gravação bruta, envie o MP4 para mapearmos os timestamps cena a cena.
