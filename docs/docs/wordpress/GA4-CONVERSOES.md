# GA4 — marcar conversões (Aero Suite)

Faça uma vez no [Google Analytics](https://analytics.google.com/) → Admin → **Eventos**.

## Marcar como conversão

| Evento | Origem |
|--------|--------|
| `cta_demo` | Clique em Agendar demonstração |
| `cta_whatsapp` | Clique WhatsApp |
| `form_submit` | WPForms enviado |
| `calendly_event_scheduled` | Reunião no Calendly |
| `generate_lead` | Lead (form ou Calendly) |
| `thank_you_view` | Página `/obrigado/` |

## Relatório sugerido

Explorar → modelo livre: dimensão `Session source/medium`, métrica `Conversions` (eventos acima).

## Consentimento (LGPD)

GA4 só inicia após o visitante clicar **Aceitar todos** no banner. Tráfego com “Somente essenciais” não entra no analytics — comportamento esperado.

## Vincular Search Console

Admin GA4 → links de produtos → Search Console.
