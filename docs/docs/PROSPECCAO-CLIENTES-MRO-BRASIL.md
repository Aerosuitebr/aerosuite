## 1. O que a ANAC certifica

| Termo | Significado |
|--------|-------------|
| **OM / Oficina** | Organização de Manutenção de Produto Aeronáutico |
| **RBAC 145** | Regulamento de certificação (antigo RBHA 145) — equivalente conceitual ao Part 145 (EUA/EASA) |
| **COM / EO** | Certificado e Especificações Operativas (capacidades, classes, produtos) |

Empresas listadas na IAC 3141 podem ser **oficina independente**, **MRO de companhia aérea**, **táxi aéreo com manutenção própria**, **fabricante** ou **base no exterior**. Para o Aero Suite, priorize quem **executa OS, rastreio de peças, AD/SB e auditoria** no dia a dia.

## 3. Critérios de fit para o Aero Suite

| Prioridade | Perfil | Por quê |
|------------|--------|---------|
| **Alta** | OM independente, ag/aviation regional, 5–80 mecânicos | OS, estoque, AD/SB, pouca TI integrada |
| **Alta** | Helicópteros / asa rotativa (HELIT, MAR, EDRA, etc.) | Job card, hangar, capacidade — alinhado ao módulo hangar/capacidade |
| **Média** | Táxi/executivo com oficina própria (Signature, Líder, etc.) | Volume menor, mas exigem rastreio e proposta/OS |
| **Média** | Operador com departamento MRO (GOL, Azul, LATAM) | Ciclo de venda longo; alto valor se entrar |
| **Baixa (parceiro)** | Fabricante (Embraer, Helibrás/Leonardo, Fibraer) | Muitas vezes ERP/MRO próprio; parceria OEM possível |
| **Indireto** | Escolas, cooperativas de MMA, despachantes | Treinamento/compliance, não core MRO |

## 6. Como rastrear e manter a lista viva

1. **Baixar** EO/COM do portal gov.br por UF ou alfabeto.  
2. **Enriquecer** com CNPJ (Receita), site, LinkedIn, frota (RAB/ANAC).  
3. **Classificar** porte: micro / pequena OM / MRO airline / OEM.  
4. **Score comercial** (0–100): classes C/D/E/F, nº aeronaves atendidas, digitalização atual.  
5. **CRM**: estágio → piloto 6 meses → case (ver `docs/PLANO-COMERCIALIZACAO-SUITE.html`).

Script sugerido (futuro): import CSV ANAC → tabela `lead_prospect` no módulo comercial.
