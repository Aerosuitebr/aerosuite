Visão Geral

Um módulo completo e independente para controle de estoque

🎯 Rastreabilidade Total

Cada produto recebe um código único de rastreio com QR Code. Saiba a origem, lote, invoice e histórico completo de qualquer item.

📦 Controle de Entrada/Saída

Registre todas as movimentações de estoque com workflow intuitivo em etapas. Controle de invoices de importação e fornecedores.

🔍 Consulta por QR Code

Use o leitor de código de barras para consulta instantânea. Pressione F2 de qualquer tela para acesso rápido ao scanner.

🎨 Layout Exclusivo

Interface dedicada para operações de estoque. Ao acessar o módulo, o sistema exibe uma identidade visual própria.

QR Code e Rastreabilidade

Como funciona o sistema de identificação única

Informações no QR Code

  • Código único de rastreio (BLW-XXXXXXXX)
  • Part Number (P/N) do produto
  • Serial Number (S/N) quando aplicável
  • Fornecedor e país de origem
  • Número da Invoice de importação
  • Código do Lote
  • Data de entrada no estoque
  • Localização (prateleira/gaveta)
  • Certificado de conformidade
  • Valor unitário (USD e BRL)

Instalação e Configuração

Passos para ativar o módulo de estoque

1

Executar Script SQL

Execute o script de criação das tabelas no banco de dados MySQL.

-- Arquivo: backend/scripts/CREATE_ESTOQUE_TABLES.sql
mysql -u root -p aerosuite < CREATE_ESTOQUE_TABLES.sql
2

Associar Funcionalidades aos Perfis

Acesse o sistema em Configurações → Perfis e associe as funcionalidades de estoque aos perfis desejados.

3

Reconstruir os Containers Docker

Rebuilde as imagens Docker para incluir as novas funcionalidades.

docker-compose down
docker rmi aerosuite-fullstack-pro-api:latest -f
docker rmi aerosuite-fullstack-pro-web:latest -f
docker-compose build --no-cache
docker-compose up -d
4

Acessar o Módulo

Clique em "Estoque" no menu lateral para acessar o módulo com sua interface exclusiva.
