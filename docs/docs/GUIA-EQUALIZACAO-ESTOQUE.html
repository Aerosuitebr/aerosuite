1
Entenda o problema

O que está acontecendo

Hoje, no sistema, existem dois lugares onde a quantidade do produto aparece. E eles não conversam entre si.

Lugar 1

Lista de Produtos (catálogo)

É o número antigo, que aparece na coluna "Quantidade" da Lista de Produtos.

Esse número não é controlado pelo sistema — alguém digitou ali um dia e ficou parado.

Lugar 2

Itens de Estoque (módulo novo)

Aqui cada peça tem nota fiscal, lote, valor, certificado e código de rastreio (QR Code).

É daqui que o sistema baixa quando uma OS é aberta com FCU.

!
Por que isso causa problema

Quando o mecânico abre uma OS, o sistema olha SÓ os Itens de Estoque. Se a peça está apenas na Lista de Produtos antiga, o sistema considera que não tem estoque e exibe "OS aberta com déficit no kit FCU" — mesmo quando a peça está fisicamente na prateleira.

✓
A solução é simples

Dar entrada das peças no módulo Estoque novo, do mesmo jeito que se faz quando chega uma nota fiscal nova. Assim os dois mundos ficam iguais e o sistema para de reclamar.

2.3 Os três tipos de problema

ClassificaçãoO que significaO que fazer

3
Pré-requisito

Antes de dar entrada — confira o Fornecedor

O sistema exige um fornecedor cadastrado em toda entrada de produto. Faça isso antes de começar a rodada:

  1. Abra o menu Fornecedores

    No menu lateral azul (Estoque), clique em Fornecedores.

  2. Veja se já existe

    Procure pelo fornecedor da peça na lista. Se já estiver lá, pode pular para o capítulo 4.

  3. Se não existir, cadastre

    Clique em + Novo Fornecedor e preencha:

    • Razão Social (obrigatório) — nome da empresa
    • País de Origem (obrigatório) — selecione na lista
    • As outras informações pode deixar em branco se não souber

    Clique em Salvar Fornecedor.

💡
Dica para peças antigas sem NF

Quando você não sabe o fornecedor original (ex.: peça que está no almoxarifado há anos), cadastre um fornecedor chamado "INVENTÁRIO INICIAL", País: Brasil. Use ele só para "carimbar" todas as entradas antigas. Combine com o supervisor antes de criar.

4
Operação principal

Como dar entrada de uma peça (passo a passo)

Vamos usar como exemplo o primeiro produto da planilha:

  • P/N: 118554
  • Nome: PIN
  • Quantidade no catálogo: 1952

  1. Abrir a tela de Entrada

    • No menu azul à esquerda, clique em Entrada (ícone de seta entrando).
    • Vai abrir a tela "Entrada de Mercadoria".
    • No topo aparecem três etapas: Origem → Produto → Localização.

  2. Etapa 1 — Origem da Mercadoria

    • Em Fornecedor, selecione o fornecedor (use "INVENTÁRIO INICIAL" se for o caso).
    • Invoice (opcional): pode deixar vazio se não tiver nota.
    • Clique no botão Próximo →.

  3. Etapa 2 — Dados do Produto

    • No campo "Buscar no cadastro de produtos", digite o P/N: 118554. Clique no produto que aparecer — o P/N, descrição e nome são preenchidos sozinhos.
    • Quantidade: digite o que está fisicamente na prateleira (use o valor da planilha apenas como referência).
    • Unidade: selecione (geralmente UN para unidade).
    • Valor unitário (USD/BRL): se souber, preencha. Se não souber, deixe vazio.
    • Clique em Próximo →.
    !
    Atenção crítica

    Se ao contar fisicamente tiver MENOS do que está na planilha (qty_catalogo), digite o número QUE VOCÊ CONTOU. A planilha é só referência do que o sistema antigo dizia. Nunca confiar cegamente no número da planilha.

  4. Etapa 3 — Localização e Certificação

    • Localização no Estoque: use o valor da coluna local_catalogo da planilha (ex.: C3).
    • Prateleira e Gaveta: preencha se souber.
    • Certificado de Conformidade: se houver. Pode deixar vazio.
    • Data de Fabricação / Validade: se souber.
    • Marque "Criar novo lote automaticamente" (já vem marcado).
    • Clique no botão verde Registrar Entrada.

  5. Conferência

    Vai aparecer uma janela verde "Entrada Registrada!" com:

    • Código de Rastreio (BLW-...)
    • Part Number
    • Lote
    • QR Code

    Pronto. A peça já está no módulo Estoque novo e o sistema vai conseguir baixar dela quando uma OS for aberta. Imprima a etiqueta se desejar. Clique em Nova Entrada para fazer o próximo produto da planilha.

Cuidado especial

Produtos duplicados no catálogo

Abra a outra planilha: produtos-duplicados-catalogo.csv. Lá aparecem P/Ns que foram cadastrados duas vezes no catálogo. Exemplo:

pncadastrosidsquantidades
118554221, 5981952
M25988-1-9162228, 53374, 138
!
Importante

Quando for dar entrada de um P/N duplicado, faça UMA VEZ APENAS. Não duplicar a entrada só porque tem dois cadastros — é a mesma peça no físico. Depois, a TI ou o supervisor unifica os duplicados em uma operação separada.

!
Atenção especial ao M25988-1-916

O cadastro 228 diz que tem 74. O 533 diz que tem 138. Conte fisicamente UMA vez e dê entrada da quantidade real contada.

7
Verificação

Como saber se deu certo

Em qualquer momento, conferir o resultado de duas formas:

Forma 1

Pela tela "Itens"

No menu de Estoque, clique em Itens. Use a busca para procurar o P/N que acabou de entrar. Deve aparecer pelo menos uma linha com status DISPONIVEL e a quantidade digitada.

Forma 2

Abrindo uma OS de teste

Peça pra alguém abrir uma OS com o FCU que tem esse P/N no kit. Se não aparecer o aviso de déficit para esse P/N específico, está correto.

Suporte

Quando pedir ajuda

Você pode mandar mensagem para a TI quando:

  • Aparecer mensagem de erro vermelha na tela.
  • O P/N que está procurando não existe no cadastro de produtos (precisa cadastrar antes — converse com o supervisor).
  • O sistema não deixar salvar a entrada mesmo preenchendo tudo certo.
  • Tiver dúvida sobre que fornecedor usar para uma peça antiga.
  • Encontrar muitos produtos duplicados além dos 10 da planilha.

Prioridade

Comece pelas linhas do topo da planilha — elas estão ordenadas pela maior diferença, ou seja, são as peças que mais "quebram" o cálculo do kit FCU quando uma OS é aberta.

Dia 1
Conferir/cadastrar fornecedores. Resolver os 5 produtos com maior diferença (118554 × 2, 379-S-17, 901211-K1, 951397).
Dias 2–3
Atacar os demais produtos "Sem entrada" (~130 linhas), preferencialmente em blocos por prateleira para otimizar a contagem física.
Dia 4
Casos "Catálogo > Estoque" (15 linhas) e "Estoque > Catálogo" (6 linhas). Conferência final com o supervisor.
Dia 5
Revisão geral + abertura de OS de teste com a TI para validar que nenhum déficit aparece nos itens equalizados.
