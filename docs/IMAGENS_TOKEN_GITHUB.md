# Referência Visual: Onde Clicar para Gerar Token

## 🗺️ Caminho Visual

```
GitHub.com
  └─ Foto de Perfil (canto superior direito)
      └─ Settings
          └─ Developer settings (menu lateral esquerdo)
              └─ Personal access tokens
                  └─ Tokens (classic)
                      └─ Generate new token
                          └─ Generate new token (classic)
```

## 📍 URLs Diretas

### Página Principal de Tokens
**https://github.com/settings/tokens**

### Criar Novo Token (Classic)
**https://github.com/settings/tokens/new**

## ⚠️ Lembrete Importante

**Você só verá o token UMA VEZ!**

Após fechar essa página, você **NÃO** conseguirá ver o token novamente.

Se perder o token:
1. Revogue o token antigo
2. Crie um novo token
3. Atualize a aplicação com o novo token
